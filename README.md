# roboleanx.com

Static marketing site. No build step — every file is served as-is.

    index.html      Home
    solutions.html  Solutions (deep links: ?p=vision, ?p=robotics)
    about.html      About
    contact.html    Contact
    assets/         images + video
    _ds/            Nocturne design-system stylesheet + bundle
    support.js      component runtime (required by every page)

## Deploy

Any static host. Publish directory: repository root of this folder.
